\# Pão de Itapeba



\## Sistema de Gestão de Estoque, Vendas e Produção



\### 1. Apresentação



O projeto Pão de Itapeba tem como objetivo desenvolver uma aplicação web para auxiliar no controle operacional de uma padaria, integrando informações de vendas, estoque e perdas.



\### 2. Problema identificado



A falta de integração entre vendas, estoque e planejamento da produção dificulta o acompanhamento dos ingredientes, provoca sobras de produtos e pode ocasionar falta de itens procurados pelos clientes.



\### 3. Objetivo do projeto



Desenvolver um sistema simples que centralize as informações operacionais, facilite o controle de estoque e contribua para reduzir o desperdício de alimentos.



\### 4. Funcionalidades previstas



\- Cadastro de produtos e ingredientes.

\- Registro de vendas e movimentações.

\- Consulta de estoque disponível.

\- Registro de perdas e desperdícios.

\- Alertas de estoque mínimo.

\- Relatórios básicos de acompanhamento.



\### 5. Tecnologias previstas



\- Python 3.13

\- Flask

\- Jinja2

\- Bootstrap

\- SQLAlchemy

\- PostgreSQL

\- Supabase

\- Pytest



\### 6. Arquitetura



Aplicação monolítica organizada em camadas, seguindo o padrão MVC (Model-View-Controller).



\### 7. Objetivo de sustentabilidade



O projeto está alinhado ao ODS 12 – Consumo e Produção Responsáveis, especialmente à Meta 12.3, relacionada à redução do desperdício de alimentos.



\### 8. Situação do projeto



Projeto em desenvolvimento. As funcionalidades serão implementadas e testadas incrementalmente.
